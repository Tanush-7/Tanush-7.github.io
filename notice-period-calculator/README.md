# Notice Period & Last Working Day Calculator

Free, single-file browser tool. Enter your resignation date and notice length to
get the standard last working day, with optional handling for days already
served and employer-approved leave adjustment.

- Calendar-day and working-day counting modes
- Shows remaining notice after days already served
- Clear notes that appointment-letter terms and written HR confirmation govern;
  the tool does date math only, no legal advice

Source problem: recurring r/IndianWorkplace notice-period threads, e.g.
