# Net Worth Snapshot Calculator (India)

Free, single-file browser tool. List assets (savings, FD, EPF, PPF, mutual funds,
stocks, gold, property) and liabilities (loans, card dues) at current values and
see your net worth as one number, with an asset/liability split.

- Pre-filled Indian asset/liability categories, all editable
- CSV export; all data stays in the browser's local storage
- Snapshot for personal clarity only - not a valuation for tax, loan or legal use
