# Fuel Mileage & Cost-per-KM Tracker

Free, single-file browser tool. Log full-tank refills with odometer readings and
get real-world km/l, cost per km, and total tracked fuel spend using the
full-tank-to-full-tank method.

- Per-fill and average mileage, cost per kilometre
- Handles out-of-order entries by sorting on odometer
- CSV export; all data stays in the browser's local storage
