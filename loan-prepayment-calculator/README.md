# Loan Part-Prepayment Calculator

See what a lump-sum prepayment does to a loan: shorter tenure at the same EMI, or a lower EMI at the same tenure.

- **Problem source**: a borrower whose extra payment was treated as advance EMI instead of part-prepayment: [r/personalfinanceindia thread](https://www.reddit.com/r/personalfinanceindia/comments/1xq53tp/).
- **Features**: EMI and remaining interest for the current loan, side-by-side comparison of both application modes, interest saved, year-wise amortization schedule, zero-rate and boundary-safe math.
- **Run it**: open `index.html` in a browser, or use the GitHub Pages site.
- **Limits**: an illustration, not advice. Assumes fixed rate, monthly reducing balance, no fees. Confirm part-prepayment treatment and charges with your lender in writing.
