# Fix My Documents (India)

A starting guide for correcting or updating common government documents - Aadhaar, PAN, passport and voter ID.

- **Problem source**: [Reddit request (87 upvotes)](https://www.reddit.com/r/bangalore/comments/10lll07/what_are_some_problems_in_india_that_you_want_a/) — "making it easier to issue/correct government documents".
- **What it does**: pick a document and what needs fixing; get typical steps, what you'll typically need, and a direct link to the official portal (UIDAI, Protean/Income Tax, Passport Seva, ECI Voters' Portal).
- **Run it**: open `index.html` in a browser, or use the GitHub Pages site.

General guidance, not legal advice. Procedures, fees and timelines change — the linked official portals are the source of truth.
